## 评测维度

每个工具我都会从这几个方面评价：

1. **上手难度**：零基础能不能快速用起来？
2. **中文能力**：能不能看懂中文、写出自然的中文？
3. **核心功能**：最擅长什么？
4. **价格**：免费版够用吗？付费值不值？
5. **使用场景**：什么时候该用它？

## 使用小技巧

> 记录一些跨工具通用的使用技巧

### 技巧1：明确告诉 AI 你是谁
```
我是针灸推拿专业的大一学生，请用我能理解的方式解释……
```

### 技巧2：给 AI 一个角色
```
你是一个有 10 年经验的中医教授，请回答……
```

### 技巧3：让 AI 一步步思考
```
请一步一步分析这个问题……
```
