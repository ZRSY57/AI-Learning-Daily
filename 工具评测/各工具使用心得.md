## 评测维度

每个工具我都会从这几个方面评价：

1. **上手难度**：零基础能不能快速用起来？
2. **中文能力**：能不能看懂中文、写出自然的中文？
3. **核心功能**：最擅长什么？
4. **价格**：免费版够用吗？付费值不值？
5. **使用场景**：什么时候该用它？

### Kimi（月之暗面）

> 评测日期：2026-09-13
> 版本：免费版（手机端）

**上手难度**：⭐⭐⭐⭐⭐
**中文能力**：⭐⭐⭐⭐⭐
**核心功能**：超长上下文，读文档神器
**价格**：基础对话免费，好模型和高级功能要开套餐

**使用心得**（2026-09-13 首日体验）：
- 注册是三个工具里最简单的：手机号+验证码就完事，不需要邮箱和信用卡
- 但手机端用起来不太方便
- 明显的"免费墙"：想换稍微好点的模型，经常提示"使用人数多，稍后重试"；一些功能要点开就引导你买套餐
- 结论：免费版适合轻度尝鲜，认真用要么排队要么掏钱。对我这种已经用 CC Switch 挂上通义千问的人来说，Kimi 定位是备用工具

### 通义千问（阿里）

> 评测日期：2026-09-13
> 版本：qwen3.7-plus + qwen3.8-flash

**选择理由**：
- 大学生资金有限，qwen性价比最高
- 两个模型搭配使用，覆盖不同场景

**分工策略**：
- **qwen3.8-flash**：快+便宜，处理简单任务
- **qwen3.7-plus**：更强+稍贵，处理复杂任务

**使用心得**（2026-09-13 首日体验）：
- 手机端感受：**手机上免费的大模型里，qwen 就不错**——不用排队、不用开套餐也能用，对比 Kimi 的"稍后重试"友好太多
- 用 CC Switch 把 Claude Code 切到通义千问线路，对话体验和平时无异
- 亲手用 API 验证了连通性：2.7 秒响应，鉴权稳定通过
- 中文理解很自然，没有翻译腔
- qwen3.8-flash 是"边想边说"的模型：先写一大段思考过程再给结论，简单任务显得啰嗦，复杂任务分析更扎实
- 踩坑记录：带中文的测试请求直接拼在命令行里会被拆坏（报 InvalidParameter），写成文件再发送就正常了
- 省钱体感：用国产模型给 Claude Code"换大脑"，成本比官方低很多，学生党友好

## 使用小技巧

> 记录一些跨工具通用的使用技巧

### 技巧1：明确告诉 AI 你是谁
```
我是针灸推拿专业的大一学生，请用我能理解的方式解释……
```

### 技巧2：给 AI 一个角色
```
你是一个有 10 年经验的中医教授，请回答……
```

### 技巧3：让 AI 一步步思考
```
请一步一步分析这个问题……
```
