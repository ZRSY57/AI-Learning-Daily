## 一、什么是 AI？

### 大白话理解

AI = Artificial Intelligence = 人工智能

简单说：**让机器做以前只有人才能做的事**。

比如：
- 你说话它能听懂 → 语音识别（AI）
- 你问问题它能回答 → 语言理解（AI）
- 你给它一张照片它能认出是谁 → 图像识别（AI）

### AI 的发展简史

| 时间 | 事件 | 说明 |
|------|------|------|
| 1950s | AI 概念提出 | 图灵问"机器能思考吗？" |
| 1960s-1980s | 寒冬期 | 技术不行，大家失望了 |
| 2010s | 深度学习爆发 | 算力够了，数据多了 |
| 2022 | ChatGPT 发布 | AI 走进普通人生活 |
| 2024-2026 | 多模态 AI | 能看、能听、能说 |

## 二、什么是大语言模型（LLM）？

### 一句话解释

**大语言模型 = 读了海量文字的"超级学霸"**

它做了这些事：
1. 读了互联网上几乎所有的文字（书、网页、论文、代码……）
2. 从中"学会"了语言的规律
3. 你给它一段话，它能接着往下写

### 它不是"真懂"，而是"概率预测"

比如你输入："今天天气真"
模型会预测下一个最可能的字：**好、热、冷、不错……**

它不是在"思考"，而是在做超大规模的模式匹配。

### 关键概念（先记住名字就行）

| 概念 | 说明 |
|------|------|
| Token | 模型处理文字的最小单位（一个字或几个字母） |
| 上下文窗口 | 模型一次能"记住"多少内容 |
| 参数 | 模型的"脑容量"，70亿、700亿这种数字 |
| 微调 | 在通用模型上针对特定领域再训练 |

## 四、注册和基础使用

### ChatGPT 注册

1. 打开 https://chat.openai.com
2. 用邮箱注册（建议用 Gmail）
3. 验证邮箱
4. 开始对话！

### 基础使用技巧

**1. 直接问问题**
```
我：用简单的话解释什么是人工智能
AI：人工智能就是让计算机……
```

**2. 让 AI 帮你做事**
```
我：帮我写一条请假短信，说明天感冒了不去上班
AI：好的，这是一条请假短信：……
```

**3. 追问和修改**
```
我：太长了，短一点
AI：好的，精简版：……
```
